¿Qué son los List Groups?

Los list groups son componentes flexibles y poderosos para mostrar series de contenido. Son perfectos para menús, listas de elementos, y navegación.

1️⃣ Lista Básica

La lista básica muestra elementos en formato vertical.

Código: 
<ul class="list-group">
  <li class="list-group-item">Elemento 1</li>
  <li class="list-group-item">Elemento 2</li>
  <li class="list-group-item">Elemento 3</li>
</ul>
Ejemplo Simple:
  • HTML5
  • CSS3
  • JavaScript
  • Bootstrap 5
  • React
Con Iconos:
  • 📱 Desarrollo Mobile
  • 💻 Desarrollo Web
  • 🎨 Diseño UI/UX
  • 🗄️ Bases de Datos
  • ☁️ Cloud Computing

2️⃣ Lista con Estado Activo y Deshabilitado

Marca elementos como activos o deshabilitados.

Código: 
<ul class="list-group">
  <li class="list-group-item active">Activo</li>
  <li class="list-group-item">Normal</li>
  <li class="list-group-item disabled">Deshabilitado</li>
</ul>
  • 🏠 Inicio - Activo
  • 📊 Dashboard
  • 👤 Perfil
  • 📧 Mensajes
  • ⚙️ Configuración - Deshabilitado

3️⃣ Lista con Badges

Combina listas con badges para mostrar contadores o información adicional.

Código: 
<ul class="list-group">
  <li class="list-group-item d-flex justify-content-between align-items-center">
    Inbox
    <span class="badge bg-primary rounded-pill">14</span>
  </li>
</ul>
  • 📥 Bandeja de Entrada 14
  • 📤 Enviados 7
  • 📝 Borradores 3
  • 🗑️ Papelera 25
  • 📦 Archivados 152

4️⃣ Lista con Colores Contextuales

Usa colores para categorizar o resaltar elementos.

  • Primary - Información Principal
  • Secondary - Información Secundaria
  • Success - Operación Exitosa
  • Danger - Error Crítico
  • Warning - Advertencia Importante
  • Info - Información Adicional
  • Light - Fondo Claro
  • Dark - Fondo Oscuro

5️⃣ Lista con Elementos Clickeables

Usa .list-group-item-action para elementos interactivos.

Código: 
<div class="list-group">
  <a href="#" class="list-group-item list-group-item-action">
    Elemento Clickeable
  </a>
</div>
🏠 Dashboard - Activo 👤 Mi Perfil 📧 Mensajes 5 nuevos 📊 Reportes ⚙️ Configuración 🔒 Premium - No disponible

6️⃣ Lista Horizontal

Usa .list-group-horizontal para listas en horizontal.

Código: 
<ul class="list-group list-group-horizontal">
  <li class="list-group-item">Item 1</li>
  <li class="list-group-item">Item 2</li>
  <li class="list-group-item">Item 3</li>
</ul>
