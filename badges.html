¿Qué son los Badges?

Los badges son pequeños componentes de conteo y etiquetado. Son perfectos para mostrar notificaciones, estados, contadores y categorías de forma compacta y visual.

1️⃣ Badges Básicos

Los badges se pueden usar con diferentes colores para indicar diferentes estados.

Código: 
<span class="badge bg-primary">Primary</span>
<span class="badge bg-success">Success</span>
<span class="badge bg-danger">Danger</span>
Todos los Colores:
Primary Secondary Success Danger Warning Info Light Dark

2️⃣ Badges en Encabezados

Los badges se escalan automáticamente al tamaño del elemento padre.

Código: 
<h1>Título <span class="badge bg-primary">Nuevo</span></h1>
<h2>Subtítulo <span class="badge bg-success">v2.0</span></h2>

Encabezado H1 Nuevo

Encabezado H2 Premium

Encabezado H3 Hot

Encabezado H4 Popular

Encabezado H5 Beta
Encabezado H6 Pro

3️⃣ Badges Redondeados (.rounded-pill)

Usa .rounded-pill para hacer badges con forma de píldora.

Código: 
<span class="badge rounded-pill bg-primary">Primary</span>
Badges Pill:
Primary Secondary Success Danger Warning Info Light Dark

4️⃣ Badges en Botones

Los badges son útiles para mostrar contadores de notificaciones en botones.

Código: 
<button class="btn btn-primary">
  Notificaciones <span class="badge bg-danger">9</span>
</button>


5️⃣ Badges como Contadores

Úsalos para mostrar cantidades, conteos o números.

🔟 Badges como Enlaces

Convierte badges en enlaces clickeables.

Código: 
<a href="#" class="badge bg-primary text-decoration-none">Badge Link</a>
Primary Link Success Link Danger Link Warning Link Info Link

✅ Mejores Prácticas

  • ✅ Usa badges para mostrar contadores pequeños y notificaciones
  • ✅ Mantén el texto de los badges corto (1-3 palabras)
  • ✅ Usa colores consistentes para estados similares
  • ✅ Combina .rounded-pill con badges numéricos
  • ✅ Asegúrate de que los badges tengan buen contraste con el fondo
  • ✅ No abuses de los badges - úsalos solo cuando sea necesario
  • ✅ Considera usar text-dark en badges claros como warning y info
