¿Qué son las Images en Bootstrap?

Bootstrap proporciona clases para hacer que las imágenes sean responsivas y aplicar diferentes estilos visuales. Las imágenes se adaptan automáticamente al tamaño de su contenedor.

1️⃣ Imagen Responsive (.img-fluid)

Hace que la imagen sea responsiva. La imagen nunca será más grande que su contenedor padre.

Código: 
<img src="imagen.jpg" class="img-fluid" alt="Descripción">
Ejemplo Visual:

Redimensiona la ventana del navegador para ver cómo se adapta la imagen.

💡 Cuándo usar: Usa .img-fluid en todas las imágenes que quieras que se adapten al tamaño de la pantalla. Es especialmente útil para sitios responsive.

2️⃣ Imagen con Bordes Redondeados (.rounded)

Aplica bordes redondeados a la imagen.

Código: 
<img src="imagen.jpg" class="rounded" alt="Descripción">
Ejemplo Visual:

.rounded

3️⃣ Variaciones de Bordes Redondeados

Bootstrap ofrece diferentes niveles de redondeo:

Clases disponibles:
  • .rounded-0 - Sin bordes redondeados
  • .rounded-1 - Bordes ligeramente redondeados
  • .rounded-2 - Bordes medianamente redondeados
  • .rounded-3 - Bordes muy redondeados
  • .rounded-circle - Imagen circular perfecta
  • .rounded-pill - Bordes en forma de píldora

4️⃣ Imagen Thumbnail (.img-thumbnail)

Agrega un borde redondeado y padding a la imagen, dándole aspecto de miniatura.

Código: 
<img src="imagen.jpg" class="img-thumbnail" alt="Descripción">
Ejemplo Visual:

.img-thumbnail

5️⃣ Alineación de Imágenes

Puedes alinear imágenes usando clases de utilidad de Bootstrap:

Clases de alineación:
  • .float-start - Alinea a la izquierda
  • .float-end - Alinea a la derecha
  • .mx-auto + .d-block - Centra la imagen

6️⃣ Figuras con Caption (.figure)

Usa el elemento <figure> para mostrar imágenes con pies de foto.

Código: 
<figure class="figure">
  <img src="imagen.jpg" class="figure-img img-fluid rounded" alt="...">
  <figcaption class="figure-caption">
    Descripción de la imagen
  </figcaption>
</figure>

✅ Mejores Prácticas

  • ✅ Siempre usa .img-fluid para hacer imágenes responsivas
  • ✅ Agrega siempre el atributo alt para accesibilidad
  • ✅ Usa .rounded-circle para fotos de perfil
  • ✅ Combina .img-thumbnail para galerías de miniaturas
  • ✅ Optimiza el tamaño de las imágenes antes de subirlas
  • ✅ Usa formatos modernos como WebP para mejor rendimiento
  • ✅ Considera usar lazy loading para imágenes que no están en viewport
