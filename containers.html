¿Qué son los Containers?

Los containers son el elemento de diseño más básico de Bootstrap. Son necesarios cuando usas el sistema de grid por defecto. Los containers se usan para contener, rellenar y alinear el contenido dentro de un dispositivo dado.

1️⃣ Container Normal (.container)

El container normal tiene un ancho máximo que cambia según el tamaño de la pantalla (responsive).

Código: 
<div class="container">
  Contenido aquí...
</div>
Ejemplo Visual:
.container - Ancho responsivo con márgenes automáticos
💡 Cuándo usar: Úsalo cuando quieres que tu contenido tenga márgenes a los lados y no ocupe todo el ancho de la pantalla.

2️⃣ Container Fluid (.container-fluid)

El container fluid ocupa el 100% del ancho disponible en todos los tamaños de pantalla.

Código: 
<div class="container-fluid">
  Contenido aquí...
</div>
Ejemplo Visual:
.container-fluid - Ancho completo 100%
💡 Cuándo usar: Úsalo cuando quieres que tu contenido ocupe todo el ancho de la pantalla sin márgenes laterales.

3️⃣ Container con Breakpoints

Puedes hacer que el container sea fluid hasta un cierto tamaño de pantalla:

Opciones disponibles:
  • .container-sm - Fluid hasta small (576px)
  • .container-md - Fluid hasta medium (768px)
  • .container-lg - Fluid hasta large (992px)
  • .container-xl - Fluid hasta extra large (1200px)
  • .container-xxl - Fluid hasta extra extra large (1400px)
Ejemplos Visuales:
.container-sm - Fluid hasta SM (576px)

💻 Ejemplo Práctico Completo

<!-- Container normal con contenido -->
<div class="container">
  <h1>Mi Sitio Web</h1>
  <p>Este contenido está dentro de un container.</p>
  
  <div class="row">
    <div class="col-md-6">Columna 1</div>
    <div class="col-md-6">Columna 2</div>
  </div>
</div>

✅ Mejores Prácticas

  • ✅ Usa .container para sitios web estándar con contenido centrado
  • ✅ Usa .container-fluid para dashboards o aplicaciones que necesitan usar todo el ancho
  • ✅ No anides containers dentro de otros containers
  • ✅ Los containers son el primer elemento dentro del <body> generalmente
  • ✅ Usa containers con el sistema de grid (row y col) para layouts responsivos
