¿Qué es Collapse?

Collapse es un plugin de JavaScript que te permite mostrar y ocultar contenido de manera animada. Es perfecto para acordeones, FAQs, menús desplegables y más.

1️⃣ Collapse Básico

El ejemplo más simple de collapse con un botón.

Código: 
<button class="btn btn-primary" data-bs-toggle="collapse" data-bs-target="#demo1">
  Toggle
</button>
<div id="demo1" class="collapse">
  Contenido a mostrar/ocultar
</div>
¡Este contenido se puede mostrar y ocultar! El collapse es una característica muy útil de Bootstrap que permite crear interfaces más limpias y organizadas.

2️⃣ Collapse con Enlace

También puedes usar un enlace en lugar de un botón.

Enlace para Toggle
Este collapse se activa con un enlace. Puedes usar botones o enlaces según tus necesidades.

Varios botones pueden controlar el mismo contenido colapsable.

4️⃣ Accordion (Acordeón)

Un accordion permite que solo un elemento esté abierto a la vez.

Código: 
<div class="accordion" id="accordionExample">
  <div class="accordion-item">
    <h2 class="accordion-header">
      <button class="accordion-button" data-bs-toggle="collapse" 
              data-bs-target="#collapseOne">
        Item 1
      </button>
    </h2>
    <div id="collapseOne" class="accordion-collapse collapse show">
      <div class="accordion-body">Contenido</div>
    </div>
  </div>
</div>

Bootstrap es el framework de CSS más popular del mundo para crear sitios web responsive y mobile-first. Incluye componentes HTML, CSS y JavaScript prediseñados.

Este estilo es perfecto para integrarse dentro de cards o contenedores.

❓ Preguntas Frecuentes

Puedes incluir Bootstrap en tu proyecto mediante CDN o descargando los archivos. Simplemente agrega los enlaces de CSS y JavaScript en tu HTML y estarás listo para usar todos los componentes.

Bootstrap 5 es compatible con las últimas versiones de Chrome, Firefox, Safari, Edge y otros navegadores modernos. No soporta Internet Explorer.

Para usar la mayoría de componentes básicos no necesitas JavaScript. Sin embargo, para componentes interactivos como modals, carousels y tooltips, Bootstrap incluye JavaScript que funciona automáticamente.

¡Por supuesto! Puedes sobrescribir los estilos con tu propio CSS o usar Sass para personalizar las variables de Bootstrap antes de compilar.

✅ Mejores Prácticas

  • ✅ Usa accordion para FAQs y listas largas de información
  • ✅ Agrega data-bs-parent cuando solo quieras un item abierto
  • ✅ Usa .show para tener un item abierto por defecto
  • ✅ Considera .accordion-flush dentro de containers
  • ✅ Usa IDs únicos para cada elemento colapsable
  • ✅ Proporciona texto descriptivo en los botones de toggle
  • ✅ No anides demasiados niveles de collapse
  • ✅ Usa collapse para mejorar la organización del contenido
