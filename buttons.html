¿Qué son los Buttons?

Los botones son elementos interactivos que permiten a los usuarios realizar acciones. Bootstrap proporciona estilos predefinidos para botones con diferentes colores, tamaños y estados.

1️⃣ Botones Básicos Sólidos

Bootstrap incluye varios estilos predefinidos para botones.

Código: 
<button class="btn btn-primary">Primary</button>
<button class="btn btn-secondary">Secondary</button>
<button class="btn btn-success">Success</button>
Ejemplos Visuales:

2️⃣ Botones Outline (Con Borde)

Botones con borde y fondo transparente. Ideales para acciones secundarias.

Código: 
<button class="btn btn-outline-primary">Primary</button>
<button class="btn btn-outline-success">Success</button>
Ejemplos Visuales:

3️⃣ Tamaños de Botones

Puedes ajustar el tamaño de los botones con las clases .btn-lg y .btn-sm.

Código: 
<button class="btn btn-primary btn-lg">Grande</button>
<button class="btn btn-primary">Normal</button>
<button class="btn btn-primary btn-sm">Pequeño</button>
Ejemplos Visuales:

4️⃣ Botones de Ancho Completo (Block)

Usa .d-grid para crear botones que ocupen todo el ancho.

Código: 
<div class="d-grid gap-2">
  <button class="btn btn-primary">Botón de Bloque</button>
  <button class="btn btn-success">Otro Botón de Bloque</button>
</div>

5️⃣ Estados de Botones

Los botones pueden tener diferentes estados: activo, deshabilitado, etc.

Código: 
<button class="btn btn-primary active">Activo</button>
<button class="btn btn-primary" disabled>Deshabilitado</button>

6️⃣ Grupos de Botones (.btn-group)

Agrupa varios botones en una sola línea.

Código: 
<div class="btn-group" role="group">
  <button class="btn btn-primary">Izquierda</button>
  <button class="btn btn-primary">Centro</button>
  <button class="btn btn-primary">Derecha</button>
</div>

✅ Mejores Prácticas

  • ✅ Usa .btn-primary para acciones principales
  • ✅ Usa .btn-outline-* para acciones secundarias
  • ✅ Agrega texto descriptivo, no solo "Click aquí"
  • ✅ Deshabilita botones durante operaciones asíncronas
  • ✅ Usa .btn-lg para botones de llamada a la acción importantes
  • ✅ Mantén consistencia en el uso de colores (success para guardar, danger para eliminar)
  • ✅ Considera agregar iconos para mejor comprensión visual
  • ✅ No uses demasiados botones primarios en una misma vista
