¿Qué son las Tables?

Las tablas de Bootstrap permiten mostrar datos de forma estructurada y organizada. Bootstrap proporciona estilos predefinidos que hacen que las tablas sean atractivas y fáciles de leer.

1️⃣ Tabla Básica (.table)

La clase base para todas las tablas de Bootstrap.

Código: 
<table class="table">
  <thead>
    <tr>
      <th>#</th>
      <th>Nombre</th>
      <th>Apellido</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>1</td>
      <td>Juan</td>
      <td>Pérez</td>
    </tr>
  </tbody>
</table>
Ejemplo Visual:
# Nombre Apellido Email
1 Juan Pérez juan@email.com
2 María González maria@email.com
3 Carlos Rodríguez carlos@email.com

2️⃣ Tabla con Rayas (.table-striped)

Agrega rayas zebra a las filas de la tabla para mejor legibilidad.

Código: 
<table class="table table-striped">
  ...
</table>
Ejemplo Visual:
# Producto Precio Stock
1 Laptop $1,200 15
2 Mouse $25 50
3 Teclado $80 30
4 Monitor $350 20

3️⃣ Tabla con Bordes (.table-bordered)

Agrega bordes en todos los lados de la tabla y las celdas.

Ejemplo Visual:
País Capital Población
Bolivia La Paz / Sucre 11.5 millones
Perú Lima 33 millones
Chile Santiago 19 millones

4️⃣ Tabla con Efecto Hover (.table-hover)

Agrega un efecto de resaltado cuando pasas el mouse sobre las filas.

Ejemplo Visual (pasa el mouse):
Curso Duración Nivel
HTML & CSS 4 semanas Básico
JavaScript 6 semanas Intermedio
Bootstrap 5 3 semanas Intermedio
React 8 semanas Avanzado

5️⃣ Tablas con Colores Contextuales

Usa clases contextuales para colorear filas o celdas individuales.

Clases disponibles:
  • .table-primary
  • .table-success
  • .table-danger
  • .table-warning
  • .table-info
  • .table-light
  • .table-dark
Ejemplo Visual:
Estado Descripción
Primary Información principal
Success Operación exitosa
Danger Error o peligro
Warning Advertencia
Info Información adicional
Light Fondo claro
Dark Fondo oscuro

6️⃣ Tabla Responsive (.table-responsive)

Hace que la tabla tenga scroll horizontal en pantallas pequeñas.

Código: 
<div class="table-responsive">
  <table class="table">
    ...
  </table>
</div>
Ejemplo Visual:
# Estudiante Matemáticas Física Química Historia Literatura Inglés Promedio
1 Ana López 95 88 92 85 90 87 89.5
2 Pedro Martínez 78 82 80 88 85 90 83.8
3 Laura García 92 95 89 91 94 88 91.5

7️⃣ Combinación de Clases

Puedes combinar múltiples clases para crear tablas más elaboradas.

Tabla Completa: .table + .table-striped + .table-bordered + .table-hover
ID Nombre Departamento Salario Estado
101 Juan Pérez Ventas $3,500 Activo
102 María González Marketing $4,200 Activo
103 Carlos López IT $5,000 Vacaciones
104 Ana Martínez Recursos Humanos $3,800 Activo

8️⃣ Tabla Pequeña (.table-sm)

Reduce el padding de las celdas para hacer la tabla más compacta.

Ejemplo Visual:
Código Descripción Cantidad
A001 Producto A 100
B002 Producto B 250
C003 Producto C 175

✅ Mejores Prácticas

  • ✅ Usa .table-responsive para tablas con muchas columnas
  • ✅ Combina .table-striped con .table-hover para mejor UX
  • ✅ Usa .table-sm cuando tengas muchos datos que mostrar
  • ✅ Utiliza colores contextuales para resaltar información importante
  • ✅ Siempre usa <thead> y <tbody> para mejor estructura
  • ✅ Considera agregar .text-center o .text-end en celdas numéricas
