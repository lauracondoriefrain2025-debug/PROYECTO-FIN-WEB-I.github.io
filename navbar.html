¿Qué es el Navbar?

El navbar (barra de navegación) es uno de los componentes más importantes de Bootstrap. Proporciona una navegación responsiva y adaptable que colapsa automáticamente en dispositivos móviles.

1️⃣ Navbar Básico

Un navbar simple con logo y enlaces.

Código: 
<nav class="navbar navbar-expand-lg navbar-light bg-light">
  <div class="container-fluid">
    <a class="navbar-brand" href="#">Logo</a>
    <ul class="navbar-nav">
      <li class="nav-item">
        <a class="nav-link" href="#">Inicio</a>
      </li>
    </ul>
  </div>
</nav>

7️⃣ Navbar Fijo (Fixed)

Usa .fixed-top, .fixed-bottom o .sticky-top.

Opciones:
  • .fixed-top - Fijo en la parte superior
  • .fixed-bottom - Fijo en la parte inferior
  • .sticky-top - Se fija al hacer scroll
Nota: Los navbars fixed se salen del flujo normal del documento. Asegúrate de agregar padding al body para evitar que el contenido quede oculto debajo del navbar. 
<nav class="navbar fixed-top navbar-dark bg-dark">
  ...
</nav>

<!-- Agrega padding al body -->
<style>
  body { padding-top: 56px; }
</style>

✅ Mejores Prácticas

  • ✅ Siempre incluye .navbar-expand-{breakpoint} para el comportamiento responsive
  • ✅ Usa .navbar-toggler para el botón hamburguesa en móviles
  • ✅ Combina .navbar-dark con fondos oscuros y .navbar-light con fondos claros
  • ✅ Usa .sticky-top en lugar de .fixed-top para mejor UX
  • ✅ Mantén el navbar simple - no sobrecargues con demasiadas opciones
  • ✅ Asegúrate de que el navbar sea accesible en dispositivos móviles
  • ✅ Usa IDs únicos para cada navbar colapsable en la misma página
  • ✅ Considera usar offcanvas para menús más complejos en móviles
